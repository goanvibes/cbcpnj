# Classic Business Centre website

Customer-facing multi-page static website for Classic Business Centre, Panjim.

## Pages
- index.html
- services.html
- gallery.html
- about.html
- contact.html
- quote.html

## Notes
- Main branch details are prefilled from the uploaded business data.
- The WhatsApp number in `js/quote.js` is a placeholder: replace `91XXXXXXXXXX` with the real number before publishing.
- The site is styled in green, blue, red, white, and black with a printing-centric visual theme.
